## 📋 실행 순서 (Claude Code가 자동 수행)

### 1단계: 컨텍스트 초기화
```
1. KST 기준 현재 날짜·시각 계산
2. 검색 시간 윈도우: 어제 06:30 KST ~ 오늘 06:30 KST (24h)
3. tool_search로 Slack MCP 로드 (slack_send_message)
4. 도구 로드 실패 시 → stderr 기록 후 exit 3
```

### 2단계: 뉴스 수집 (최소 9회 web_search)

**검색 조건**
- 기간: 최근 24시간 → 부족 시 48시간 자동 확장
- 국가: 미국 4~5건 + 한국 1~2건 = **총 5~7건** (일반 AI 뉴스)
- **추가**: SNS 플랫폼 4종(인스타그램·쓰레드·틱톡·X) — 플랫폼별 최소 1회씩 검색
- 우선 카테고리:
  1. 🚀 신규 모델/제품/기능 발표
  2. 🏢 빅테크 동향 (OpenAI, Anthropic, Google, Meta, MS, xAI, NVIDIA, Apple)
  3. ⚠️ 사건사고·소송·보안·장애
  4. 📜 정책·규제 (백악관, EU AI Act, 한국 AI 기본법, FTC, 개인정보위, 공정위)
  5. 💰 펀딩·M&A·인사이동
  6. 🇰🇷 한국 빅테크 (네이버, 카카오, 삼성, LG, KT, SKT) — 이슈 있을 때만
  7. 📱 SNS 플랫폼 업데이트·기능 변경·이슈 (인스타그램·쓰레드·틱톡·X) — 매일 필수 확인

**검색 쿼리 템플릿**
```
[일반 AI]
1) "AI news" + 오늘 KST 날짜
2) "OpenAI" OR "Anthropic" OR "Google AI" 최신
3) "AI announcement" OR "AI launch" 24시간
4) "AI regulation" OR "AI lawsuit" 미국
5) "AI 뉴스" OR "인공지능" 한국 최신

[SNS 플랫폼 — 플랫폼별 필수]
6) "Instagram" update OR feature OR outage OR issue (24h)
7) "Threads" (Meta) update OR feature OR news (24h)
8) "TikTok" update OR feature OR ban OR lawsuit OR outage (24h)
9) "X" OR "Twitter" (Elon Musk) update OR feature OR outage OR policy (24h)

+ 필요 시 web_fetch로 1차 소스 본문 확인
```

**선별 규칙**
- **1차 소스 우선** (Bloomberg, Reuters, WSJ, FT, TechCrunch, The Verge, The Information, 연합뉴스, 매일경제, ZDNet Korea, 공식 블로그/뉴스룸, 각 플랫폼 공식 뉴스룸)
- 단순 재게재·번역 사이트 제외
- 중복 이슈는 가장 권위 있는 1건만 채택
- **저작권**: 한 출처당 인용 15단어 미만, 1회 이내
- **SNS 항목**: 각 플랫폼당 핵심 1~2건. 확인된 1차 소스가 없으면 임의 추정·창작 금지 → "새로운 내용이 없습니다"로 명시

**필수 준수**
- ✅ 모든 뉴스에 **원본 기사 URL 전체** 포함
- ✅ 슬랙 링크 문법 `<URL|표시텍스트>` 사용
- ✅ 매체명 + 발행 시각 표기
- ✅ 미국 깃발 🇺🇸 / 한국 깃발 🇰🇷 으로 국가 구분
- ✅ **SNS 4종(인스타그램·쓰레드·틱톡·X)은 소식 유무와 무관하게 매일 4줄 모두 표기** — 새 소식 없는 플랫폼은 반드시 "새로운 내용이 없습니다"로 명시
- ✅ SNS 항목은 업데이트 / 기능 변경 / 사건·이슈를 항목별(불릿)로 나열
- ❌ URL 축약/생략 금지
- ❌ SNS 항목 임의 추정·창작 금지 (확인된 1차 소스 없으면 "새로운 내용이 없습니다")

### 4단계: 슬랙 전송 (Slack MCP 호출)

```python
Slack:slack_send_message(
    channel_id="C0B5UQZL1NJ",   # #ai-news 고정값
    message=<3단계에서 생성한 메시지>
)
```

- 사전 승인된 채널 ID 외 발송 금지
- 전송 실패 시 **최대 2회 재시도** (지수 백오프: 30초, 2분)
- 최종 실패 시 exit 1

### 5단계: 로그 저장 (스레드 댓글)

발송된 메시지의 `message_ts`를 받아서, 같은 채널 해당 스레드에 메타데이터 댓글 추가:

```python
Slack:slack_send_message(
    channel_id="C0B5UQZL1NJ",
    thread_ts=<발송된 메시지의 message_ts>,
    message="""
🔍 **검색 메타데이터**
• 검색 쿼리: 9건 (AI 5 + SNS 4)
• 채택 뉴스: 7건 (미국 5 + 한국 2)
• SNS 업데이트: 인스타 <n> / 쓰레드 <n> / 틱톡 <n> / X <n>
• 시간 윈도우: 24h
• 실행 시간: <KST timestamp>
"""
)
```
